# LeafDx web app

Next.js 16 (App Router, TypeScript, Tailwind CSS 4, shadcn/ui) PWA that runs the MobileNetV1
model in the browser with TensorFlow.js. Photos are not uploaded; the optional Grad-CAM heat
map calls the API in `../api` only when the user asks.

```bash
npm install
npm run dev            # http://localhost:3000 (copies the TF.js wasm files first)
npm run lint && npm run typecheck && npm test
npm run build && npm run e2e   # Playwright, desktop + mobile viewports
```

| Path | What it is |
|---|---|
| `public/model/` | TF.js graph model (float16 weights), exported from `ml/` |
| `src/data/classes.json`, `research.json` | generated by `python -m leafdx.train.export_web` from the ML results; do not edit |
| `src/data/diseases.json` | disease descriptions with sources (draft, needs expert review) |
| `src/lib/verdict.ts` | confidence thresholds and the "not a leaf" check |
| `scripts/verify-model.mjs` | checks the TF.js model against the Keras model (`npm run verify-model`) |

Environment: `NEXT_PUBLIC_API_URL` (optional) is the base URL of the Grad-CAM API.

Docker: `docker build -t leafdx-web web` (see `Dockerfile`). Deployment on Vercel:
[`../docs/deployment.md`](../docs/deployment.md).
